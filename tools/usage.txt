面试教练 · 单机版(便携版)使用说明
==================================

一、运行环境
------------
- 64 位 Windows 10 / 11
- 不需要安装 Rust / Node / MySQL / Redis / VC++ 运行库,依赖全部内置

二、怎么用
----------
1. 把整个文件夹解压到任意目录(路径尽量不含特殊字符)
2. 双击  启动面试教练.cmd
3. 浏览器会自动打开 http://127.0.0.1:8080
   (没自动打开就手动访问这个地址)
4. 首次使用:右上角「设置」-> 填 Base URL / API Key / 模型名 -> 「测试连接」-> 保存

   常用大模型配置:
   - DeepSeek        https://api.deepseek.com                      deepseek-chat
   - 通义千问        https://dashscope.aliyuncs.com/compatible-mode qwen-plus
   - 本地 Ollama     http://localhost:11434/v1                     qwen2.5:7b(需先装 Ollama)

5. 关闭:关掉那个黑色命令行窗口即可

三、数据存在哪
--------------
- config.toml                 首次运行自动生成,大模型配置(含 API Key)
- data\interview-coach.json   全部面试记录 / 简历 / 报告
备份就把这两个文件拷走;换机器拷过去即可继续用。

四、常见问题
------------
1) 双击后报「应用程序控制策略已阻止此文件」或「os error 4551」
   本机开启了 Windows 智能应用控制(Smart App Control),它会拦截未签名的 exe。
   处理办法:Windows 安全中心 -> 应用和浏览器控制 -> 智能应用控制 -> 关闭(需重启),
   或换一台没开这个功能的机器。注意:关闭后不可再次开启,公司电脑请先问 IT。

2) 双击后弹「Windows 已保护你的电脑」(SmartScreen)
   点「更多信息」-> 「仍要运行」即可。这是因为 exe 没有代码签名。

3) 杀毒软件报警/隔离
   未签名的 165MB 单文件 exe 容易被误判,需要找 IT 加白名单。

4) 提示端口被占用 / 想换端口
   用命令行运行:interview-coach.exe --port 9000
   加 --no-browser 可以不自动打开浏览器。

5) 页面空白或 404
   检查 web 目录是否和 exe 在同一层(必须一起拷贝,不能只拷 exe)。

五、说明
--------
- 本包为 debug 构建(带调试符号,所以体积较大),功能与 release 版完全一致。
- 服务只监听 127.0.0.1,数据全部留在本机,除调用大模型外不联网。
